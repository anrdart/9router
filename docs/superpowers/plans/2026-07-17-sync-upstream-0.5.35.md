# Sync upstream v0.5.35 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Merge upstream `v0.5.35` (26 commits, 0.5.31–0.5.35) into the `go` branch while preserving every local feature (Go backend, AgentRouter, ZCode, moderation fallback, security patchset), then rebuild the global `9router` package from the fork.

**Architecture:** `git merge upstream/master` into `go`. The merge-base is clean at `v0.5.30`, so this brings only the 0.5.31–0.5.35 delta. Overlapping files are mostly additive in distinct regions (auto-merge); only 4 files need manual version-bump resolution. After merge, regenerate the Go model snapshot, run the full test matrix, then cross-compile and install the global tarball.

**Tech Stack:** Git, Bun, Next.js 16 standalone, Go 1.24, SQLite (sql.js + better-sqlite3), esbuild.

**Spec:** `docs/superpowers/specs/2026-07-17-sync-upstream-0.5.35-design.md`
